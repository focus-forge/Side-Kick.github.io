2. Description of Service

SideKick is a productivity and focus management application designed with neurodivergent users in mind. The App provides, among other features:

  • Friction-based app blocking via Apple's Screen Time API
  • Focus schedules with automatic time-based blocking
  • Quick Focus sessions with configurable blocking
  • Brain Dump capture (text and voice) with an inbox for processing thoughts
  • Task management (Now / Next / Later)
  • Energy check-in tracking
  • Focus scoring, progress tracking, and insights

7. Screen Time API and App Blocking

SideKick uses Apple's Screen Time API (Family Controls framework) and the Device Activity framework to apply app blocking. By granting Screen Time permission, you authorise the App to:

  • Apply shield screens over apps and website categories you select for blocking
  • Remove shields based on your settings, schedules, and unblock requests
  • Monitor Device Activity events to know when a focus schedule starts and ends
  • Display shield configuration screens when you attempt to access a blocked app
Important Limitation: App blocking in SideKick is provided on a best-effort basis using Apple's native Screen Time framework. We do not guarantee that blocking will prevent all access to selected apps in all circumstances. iOS system updates, device reboots, permission changes, or unusual device states may temporarily affect blocking behaviour. SideKick is a productivity tool and is not a parental control solution or security product. You remain responsible for your own device usage.

You can revoke Screen Time access at any time through iOS Settings. Doing so will disable all app blocking functionality.
